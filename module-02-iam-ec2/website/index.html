Build steps

  1. IAM first: created the operator user and a custom least-privilege policy (groups are blocked by my account's SCP).
  2. Instance role: EC2-WebServer-Role with AmazonSSMManagedInstanceCore.
  3. Security Group: only HTTP inbound; no SSH from the internet.
  4. Launch: Amazon Linux 2023 on a free-tier eligible instance in {{REGION}}, IMDSv2 required.
  5. User data: installs NGINX, reads instance metadata and publishes this page on first boot.
