Module 07 · Final AWS Cloud Deployment Project

Every internship application, one serverless board.

InternTrack keeps applications moving from wishlist to offer. The page is served from Amazon S3 and every change goes through API Gateway → AWS Lambda → Amazon DynamoDB, monitored by CloudWatch.

Add an application

Pipeline

Change a status to move a card — the update is saved in DynamoDB instantly.

How it runs on AWS

Everything is defined as code in one AWS CloudFormation template and deployed with a single script.

S3

Amazon S3

Static website hosting for this single-page app.

API

API Gateway (HTTP API)

6 routes, CORS, throttling (10 req/s, burst 20).

λ

AWS Lambda

Python 3.13 CRUD + stats logic with input validation.

DDB

Amazon DynamoDB

Table InternTrack-Applications, key id, 5 RCU / 5 WCU.

CW

Amazon CloudWatch

Dashboard, structured logs and an error alarm.

IAM

AWS IAM

Lambda role limited to 5 DynamoDB actions on one table.
